# 映选 · 115 云端视频预筛与归档工作台

基于 `p115client` + 本地 `SQLite` + `hls.js` + `Aria2` 的云端视频筛选工作台。实现 **「云端在线预筛淘汰 97% → 精选 3% 保持原目录相对路径集中归档 → Aria2 自动批量落盘」**。

## 快速开始

1. 安装依赖（Python 3.10+）：
```bash
pip install -r requirements.txt
```

2. 启动本地 Aria2 RPC（或使用 Motrix）：
```bash
aria2c --enable-rpc --rpc-listen-all=false --rpc-listen-port=6800
```

3. 启动服务：
```bash
python app.py
```
浏览器打开 `http://127.0.0.1:81/dy/`（支持环境变量 `VIDEO_TAG_PORT` 修改端口）。

4. 配置并开始筛选：
- 点击顶部或菜单中的 **「115 账户与目录配置」**，填入：
  - **115 Cookie**（或放置 `115-cookies.txt` 在项目根目录，支持扫码自动刷新）
  - **云端待筛选目录 (`INBOX_CID`)**：支持数字 CID 或路径（如 `/待筛选目录`）
  - **云端精选集中目录 (`TARGET_CID`)**：支持数字 CID 或路径（如 `/精选集中营`）
  - **本地保存目录 (`LOCAL_SAVE_DIR`)** 与 **Aria2 RPC** 地址
- 点击 **「同步云端」**，自动拉取待筛选目录并利用 115 原生 `sha1` 秒级拦截重复视频。
- 使用快捷键 **`Z`（保留 5 分） / `X`（淘汰 1 分） / `↑↓`（切换） / `←→`（快进退）** 快速打标，毫秒级写入本地 SQLite。
- 筛选完毕后点击右上角 **「结算归档 (3%)」**，后台自动完成：
  1. 按原目录相对路径结构将精选视频集中移动到 115 `/精选集中营`
  2. 每批 500 个批量删除淘汰视频（进 115 回收站兜底）
  3. 逐个获取精选原画直链并推送到本地 Aria2，按原目录相对路径自动落盘

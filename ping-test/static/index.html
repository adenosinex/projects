命令行调用

不用打开网页，直接用 curl 测。同步接口会等测完才返回完整结果；一次最多 50 个目标，同时只能跑一个测试（正在跑时返回 409）。

GET（最简单，多个 target 参数）：

curl --max-time 120 "https://cpl.zin7.de/ping/__TOKEN__/api/ping?target=8.8.8.8&target=1.1.1.1&count=4&workers=10"

POST（JSON 传参，和网页版一样的字段）：

curl --max-time 120 -X POST "https://cpl.zin7.de/ping/__TOKEN__/api/test-sync" \
  -H "Content-Type: application/json" \
  -d '{"targets":["8.8.8.8","1.1.1.1","223.5.5.5"],"mode":"ping","count":4,"workers":10}'

TCP 模式（禁 ping 的主机）：

curl --max-time 120 "https://cpl.zin7.de/ping/__TOKEN__/api/ping?target=223.5.5.5&mode=tcp&tcp_port=443"

返回完整结果 JSON：run_id、status、elapsed_s、每个目标的收发包数 / 丢包率 / min / avg / max、summary。同步调用会阻塞到测完，--max-time 建议给 120 秒；token 错了返回 404。
